# SportShield AI 🛡️

SportShield AI is an enterprise-grade platform designed for automated copyright and intellectual property (IP) protection across the digital landscape. Utilizing advanced AI engines, it monitors multiple platforms in real-time to detect unauthorized content, assess risk, and streamline the enforcement process.

## 🌟 Key Features

### Command Center Dashboard
Get a comprehensive overview of your protected assets, active violations, and real-time detection feeds. The dashboard provides match confidence scores and risk levels for every detected instance across platforms like YouTube, Twitch, and social media.

![Command Center Dashboard](assets/dashboard.png)

### Risk Intelligence & Analytics
Dive deep into your enforcement data. Track risk detection trends, view top infringing platforms by volume, and monitor the overall health of your intellectual property portfolio with intelligent insights.

![Risk Intelligence](assets/analytics.png)

### Automated Legal Takedowns
Streamline the enforcement process with the Legal Takedown Center. Generate automated DMCA and intellectual property takedown notices directly within the platform, complete with live previews and legal context generation.

![Legal Takedown Center](assets/legal.png)

## 🚀 Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set the `GEMINI_API_KEY` in `.env.local` to your Gemini API key
3. Run the app:
   ```bash
   npm run dev
   ```
